# فيلم تدشين مهاد: «خيطٌ واحد» (النسخة الأولى)

النسخة الأولى من الفيلم (Rough cut) مبنية على الستوري بورد في الـArtifact «فيلم تدشين مهاد»: 20 لقطة و89.5 ثانية، 1920×1080 و25fps.

## ما في هذه النسخة (v2)

| الحالة | اللقطات |
|---|---|
| موشن جاهز (يمكن اعتماده أو تحسينه) | S01 النقطة · S03 الحلقات · S06 العقدة · S07 (✓ على شاشة الحجز) · S08 من الواجهة للنسيج · S09 نسج 96 · S11 خيطٌ جديد · S13 كشف الشعار · S14 Learn Without Limits · S18 الشبكة |
| لقطات AI من Higgsfield، وفيها واجهات مهاد داخل الشاشات الخضراء | S04 الفريق · S07 اليدين والخيط · S15 الطالب · S16 المعلمة · S17 ولي الأمر · S19 الرياض (بديل الدرون) |
| مؤقت بانتظار المادة | S02 · S05 (موادكم الحقيقية) · S12 (التقاط 4K عربي) |
| ملفات رسمية فقط (مكانها محجوز) | S10 صور القيادة · S20 الشعار المتحرك لليوم الوطني |

- **كشف الشعار (S13):** عقدة S06 هي نفسها «ه» في شعار مهاد، واستُخرج مسارها من ملف الشعار. آخر إطار هو ملف الشعار نفسه دون تعديل. في النسخة النهائية يُستخدم «لوجو مهاد المعتمد.ai» بدل الـPNG.
- **التعليق الصوتي:** تسجيل Sterling (ElevenLabs، النسخة 67.8 ثانية)، مقسّم إلى 20 سطرًا، وكل سطر في وقته حسب الستوري بورد. التوقيت في `engine/assets/vo_timing.json`، والترجمة على الشاشة تتبعه.
- **الموسيقى والمؤثرات:** مؤقتة مولّدة بالكود (`audio/temp_score.py`) حسب خريطة الموسيقى، وتنخفض نحو 8dB تحت الصوت.
- **الواجهات داخل الشاشات:** لقطات إنجليزية مؤقتة. النهائي بالواجهة العربية بحساب تجريبي.

## التشغيل

```bash
python3 -m http.server 8765 --bind 127.0.0.1   # من داخل film/
# معاينة تفاعلية: http://127.0.0.1:8765/engine/index.html  (?t=52 للقفز، ?notags ?nosubs للإخفاء)
node render.mjs stills 12.2,35.4,54        # إطارات ثابتة ← out/stills
./render_all.sh [notags]                   # الفيلم كامل ← out/video_silent.mp4 (4 أجزاء بالتوازي)
python3 work/prep_footage.py               # مقاطع AI (src/clips) ← إطارات مع الواجهات في الشاشات الخضراء
python3 audio/temp_score.py                # الموسيقى المؤقتة ← audio/temp_score.wav
python3 audio/vo_mix.py [take.mp3]         # تقسيم الصوت ووضعه في وقته + الميكس ← audio/final_mix.wav
```

يحتاج Node مع Playwright وChromium، وffmpeg (`pip install imageio-ffmpeg`)، وPython مع numpy وscipy وpillow وscikit-image.
